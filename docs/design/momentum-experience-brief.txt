Home
Visible Explore, My Work, Progress; global Share.

Carousel features three projects with distinct outcomes, owners, adoption counts and illustrations. Start paused. Support explicit Play/Pause, previous/next, position dots and manual keyboard/swipe navigation. After keyboard focus, do not restart rotation without explicit user action.

Visual direction
Graphite ground #0b0c0e; dark foreground surface #161b21; ice-blue accent #92c9f5. Product preview uses a light blue stage and a near-white paper foreground. Make depth with distinct material/tonal planes, readable contrast, overlap within the preview illustration, and purposeful shadows. Do not return to copper or a wall of equal dark boxes. No external media needed; illustrations are native UI artifacts tied to project contents. Preserve legibility on smaller screens; omit elaborate artwork before sacrificing content.

Context and drill-in
Project details open in a right-side modal panel with the current page visible underneath. Summary, benefit and next action first; conversation and technical details remain optional. Project id is in the URL. Preserve search text, filter, carousel slide and scroll context through close/Back; history state and same-tab session storage support refresh. Search and filtered inventory remain discoverable; do not force every category and action onto home.

Research and interpretation
NN/g progressive disclosure: show core choices first and make secondary detail easy to reach. https://www.nngroup.com/articles/progressive-disclosure/
W3C carousel pattern: explicit rotation control, keyboard support and stopping on focus. https://www.w3.org/WAI/ARIA/apg/patterns/carousel/
Material 3 elevation: tonal surface roles and shadow both communicate elevation. https://developer.android.com/develop/ui/compose/designsystems/material2-material3
The showcase/feed layout, ice palette and contextual panel are design decisions informed by these principles, not claims that research mandates this exact composition.
